## What it does

**Four steps, nothing overwhelming:** Style → Materials → Details → Make it. Every choice comes with an industry-default recommendation and a one-line reason, so you can go deep or just accept the defaults.

### Clothing, hats & bags
- **181 parametric templates** (161 clothing, knitwear, underwear, hosiery, hat & bag + 20 jewelry), including **23 jeans cuts** (straight, slim, skinny, tapered, relaxed, baggy, bootcut, flare, bell-bottom, barrel, mom, dad, boyfriend, carpenter, low-rise, cropped, raw selvedge, cigarette…): crew/V-neck tees, undershirts, tanks & A-shirts, henleys, polos, oxford & dress shirts, hoodies, crew sweats, denim trucker, bomber, biker, racer, waxed field jacket, Harrington, chore coat, varsity, puffer, parka, rain shell, anorak, gilet, single- and double-breasted blazers (notch / peak / shawl lapels), suits, waistcoats, overcoats, trench, peacoat, dresses, skirts, jeans, chinos, cargo, joggers, 5" and 7" shorts, scarves, ties, bow ties, and all kinds of hats (tuque/beanie, slouch, bucket, fedora, trilby, Panama, beret, 6-panel baseball cap, snapback, trucker, dad cap, 5-panel, flat cap, visor) and bags (tote, shopper, duffel, weekender, handbag, clutch, crossbody, sling, fanny pack, backpack, messenger, bucket, baguette, hobo).
- **Customise everything**: fit, length, sleeves, cuffs (rib, barrel, French, button-tab, zip, storm…), necklines, collars, lapels, closures, pockets, vents, belts, rise, leg shape, waistbands, hems, cap bill inserts (polyethylene, cardboard, buckram…), bag handles, closures and hardware.
- **Any body**: realistic CC0 male & female mannequins; size charts XXS–4XL **or** custom height, weight, chest/bust, underbust, waist, hips, thigh, shoulder width, inseam, arm length, neck and head, plus body-shape presets (hourglass, pear, apple, rectangle, inverted triangle, athletic, petite, tall, plus, slim). Mesh, collisions and patterns all follow the body.
- **Tailoring**: take in / let out chest, waist, hips, thigh; lengthen / shorten body, sleeves, legs; adjust shoulders and leg openings, with a **fit map** (red = tight, blue = loose).
- **Hosiery & socks**: tights, pantyhose, fishnets, stockings, hold-ups, footless tights, no-show to over-knee socks; denier, yarn, patterns (fishnet, micro-net, rib, cable, argyle, stripes, lurex, back seam), lace / rib / welt tops, reinforced toe & heel, cushioning.
- **Zippers**: metal (brass, antique brass, nickel, gunmetal, aluminium, premium polished), nylon coil, invisible, water-resistant, moulded, reversible, decorative; #3–#10; closed / open-end / two-way; auto-lock / non-lock / reversible sliders; puller styles; industry defaults per garment.
- **Decorative edges & lacing**: scalloped, lettuce, picot, ruffle, frayed, pinked, piped, bias-bound, blanket stitch, ric-rac, fringe, lace, pom-pom, feather, sequin edges; crisscross, ladder, corset and spiral lacing with eyelets.
- **Parametric sizing**: men's / women's / unisex charts XXS–4XL or your own measurements. Patterns *and* the avatar re-draft; the tech pack includes the graded spec.
- **Fabrics with real quality differences**: 166 fabrics and qualities across 63 families (virgin wool, Super 130s, Japanese selvedge denim, distressed / stone-washed / acid-wash denim, pre-shrunk / combed / Pima / Supima / organic cotton, Egyptian poplin, waxed cotton, ripstop, ballistic nylon, PFAS-free waterproof membranes…), **fibre blends** with pros/cons (CVC 60/40, T/C 65/35, tri-blend, 98/2 stretch denim, 80/20 nylon-spandex…), and **insulation** (goose/duck down by fill power, synthetic microfibre, wool batting, kapok, aerogel…).
- **Underwear & lingerie**: men's briefs, trunks, boxer briefs, boxer shorts, long johns; women's bikini, hipster, thong, high-waist, boyshort, lace bralette, sports bra, underwire balconette, bandeau, camisole. Brief cuts, rise, leg height and waistbands (exposed jacquard, fold-over, picot, laser-cut bonded); bras with band/cup sizing, straps (standard, racer, halter, convertible, strapless), closures, underwire and padding/moulded foam; intimates fabrics (nylon-elastane microfibre, modal, power mesh, stretch lace, bra foam, stretch satin) and lingerie hardware (hooks & eyes, sliders, rings, underwire, picot/plush/fold-over elastics).
- **Knitwear**: fully-fashioned, whole-garment (seamless), cut & sew, circular, hand-knit and crochet; gauges 1.5–18gg; 18 yarns (extra-fine merino, Shetland, Aran, cashmere, mohair-silk, alpaca, cotton, linen…); 23 stitch structures (jersey, rib 1x1/2x2, fisherman rib, Milano, garter, seed/moss, cables, Aran, honeycomb, pointelle, lace, popcorn, waffle, tuck, jacquard, Fair Isle, intarsia…); colourwork motifs (Fair Isle bands, Nordic star, argyle, birdseye, houndstooth, snowflake yoke) with a printable **knitting chart**; 13 knit templates. Knit choices change weight, stretch and drape in the simulation.
- **Assembly**: every ISO 4915 stitch class plus seam constructions, hand stitches, bonding & glue, ultrasonic / RF / laser welding, seam taping, fusing, rivets, linking and whole-garment knitting, with **thread materials** (core-spun, bonded nylon, silk, aramid, PTFE, conductive steel…).
- **Colour, dye, print & paint**: 20+ dye methods (reactive, garment-dyed, indigo rope, dope-dyed, tie-dye, shibori, batik, ombré…), 32 print designs (big cats: leopard, cheetah, tiger, cougar, jaguar, snow leopard; plus zebra, snakeskin, tartan, houndstooth, argyle, chevron, ikat, ditsy floral…) printed at true real-world scale with a print-size control and 20 print methods (screen plastisol/water-based/discharge, DTG, DTF, sublimation, puff, foil, devoré…), paints, and fibre-compatibility checks.
- **Trims & decorations**: 76 buttons, fasteners and decorations (horn, corozo, MOP, jeans tacks, snaps, zips, studs, spikes, rhinestones, pearls, sequins, chains, fringe, patches…).
- **Properly drafted patterns**: true drafted curves for necklines, armholes, sleeve caps (solved to fit the armhole), crotch and seat seams; shirts, jackets, coats and cardigans are cut as **separate overlapping fronts** that fasten at the centre line; lapels fold back along the roll line; **3D collars** (point, spread, button-down, camp, polo, band, funnel, tailored suit collars, rib neckbands, hoods) follow the sewn neckline. Every template ships with its **topstitching and seams drawn in**.
- **Flat pattern canvas (the manufacturing view)**: every garment broken down into its cut pieces, laid flat: **cut line and stitch line** with seam allowance (deeper on hems), seams colour- and **letter-matched** with notches (A sews to A), grainlines, piece labels, pocket / placket / button placements, topstitch lines. View all pieces or **step through one piece at a time** with dimensions, area and seam lengths; **side by side with the 3D garment** (drag a pattern point and the garment re-drapes). **Grade nest** overlays every size; **marker** lays the pieces on your fabric width and reports metres per garment. **Draw your own pieces from scratch**, sew edges together, or start from a blank design. No AI needed for any of it.
- **Wear it and handle it**: zip and unzip by clicking the zipper, button and unbutton single buttons, hood up or down (a real sewn hood that drapes on the head), roll sleeves, open the fly, cuff or tailor hems, and **✋ Pull** to grab the cloth and tug it with real cloth physics.
- **Embroidery, logos & artwork**: lettering, motifs or your own PNG / JPG / SVG, stitched (fill, satin, cross-stitch, 3D puff, appliqué, chenille) with up to 15 thread colours, or printed, placed anywhere on any piece.
- **Machine code for the factory**: Tajima **.DST** embroidery files with run sheets, **Knitout** programs per knitted panel plus written knitting instructions, the **sewing operations bulletin** (every operation in order with stitch, machine, thread, SPI and seam length), print and dye protocols with repeat artwork, and a one-click **manufacturing pack (ZIP)**. Files open in an in-app **viewer** where you can edit, undo/redo, reset or save edits, print, and download to a folder you choose.
- **Any body, any scale**: import your own mannequin (STL, OBJ, PLY, GLB, FBX, DAE, 3MF, STEP) and make garments at miniature scale (1:2 down to 1:20) for dolls, puppets and merch; skin tones.
- **Pockets, outside and inside**: 30 constructions, each adding its real cut pieces (bags, welts, flaps, facings, interfacing) and slash lines to the pattern (patch, flap, box-pleat, bellows/cargo, single and double welt, flap-jetted, ticket, breast welt, slanted hand-warmer, zip, Napoleon, in-seam, jeans scoop / coin / five-point back, tool and hammer loop, sleeve utility, inside breast, phone, pen, poacher's, security zip, hidden waistband…). Pick one and click the garment to place it; choose closure and angle.
- **Whole outfits**: wear any number of pieces at once (underwear, base layers, knits, jackets, coats, hats, bags, hosiery). Layers stack in the right order automatically (or set them by hand), and inner layers stay under outer ones in the simulation.
- **My collection**: save every design you make (Ctrl+S), with a thumbnail, to a wardrobe on your device. Open, rename, duplicate or delete pieces, filter garments / outfits / jewelry, export and import the whole collection, and **put any saved piece on with the current outfit**, keeping all its fabrics, colours, prints, trims, zippers and edges.
- **Realistic male & female mannequins** (CC0, generated from MakeHuman) graded to every size, with collision shapes fitted to the mesh so cloth rests on the body you see.
- **Real cloth simulation**: sew-then-drape like garment CAD on outline-conforming triangle meshes. Cloth collides with a **distance field of the actual mannequin mesh** (not capsules), so garments sit on the real neck, shoulders, chest and seat. Every material has a **default thickness and weight you can override per project** (thickness changes stiffness and stand-off, weight changes the hang). Each fabric is driven by **measured textile behaviour** (extensibility, shear stiffness, bending rigidity and friction from fabric objective measurement), so denim hangs like denim and chiffon like chiffon. Mannequin stands in a natural **A-pose (arms at 45°)**. It runs in **Rust → WebAssembly** (20 KB, zero-copy to the GPU) and sleeps when settled, so it uses no CPU at idle.

### Shoes & boots
- 70 types (dress, loafers, sneakers, work and hiking boots, western, heels, flats, sandals), each lasted on the mannequin's own feet; a heel pitches the foot and the body rises on the sole.
- Real upper pieces (vamp, quarters, cap, counter, backstay, facings, tongue, collar), each in its own material and colour; welt, midsole, outsole, tread and heel by named construction (Goodyear, Blake, stitchdown, cemented, vulcanised...).
- Lace hardware you can see: punched holes, eyelets, D-rings, webbing loops and solid speed hooks, with the lace threaded in six lacing patterns.
- Flat pattern pieces, lace length, hardware counts and a footwear spec for the maker.

### Studio tools
- Any sub-piece (collar, cuffs, lapels, pockets, plackets, straps) in its own material and colour.
- Colourways, rendered side by side; every size rendered as a size run; turntable video.
- Costing per unit with your own material, trim and labour prices, through to FOB, wholesale and retail, in the tech pack.
- Version history (automatic copies you can restore), search everything with Ctrl+K.
- Pull the cloth, pin it (Shift+click), pinch both sides at once, rip a seam open with frayed edges, measure the body at any height.

### Jewelry
- Chain links are dimensioned so **neighbouring links never intersect** (verified by an automated interference test for every chain type): true twisted, diamond-cut **Cuban and curb** links, cable, rolo, mariner, paperclip, box, and swept rope / wheat / snake chains; the **signet ring** is one solid with tapered shoulders and a flat face.
Rings, chains (19 link types incl. cable, curb, Cuban, figaro, rope, box, franco, byzantine, paperclip, tennis), necklaces, pendants, bracelets, bangles, cuffs and earrings, with clasps, bails and backs; 34 gems with real refractive index & dispersion; 17 cuts incl. custom; 14 settings; **karat control** (purity, density, colour, hallmark), platings; custom outlines for pendants, stones, links and signets; **import CAD parts** (STL, OBJ, GLB, 3MF, PLY, FBX, DAE, STEP, IGES, .blend) and resize, stretch and distort them to fit; metal weight & carat estimates; STL export for casting.

### Make it
One click for a **tech pack** (flats, BOM, construction, colour/print spec, graded measurements, labels/care, QC/AQL), **DXF** pattern for factory CAD, **SVG**, **tiled print-at-home PDF**, **BOM CSV**, **GLB/OBJ/STL**, a step-by-step **production guide** (finding mills, trim suppliers and factories, sampling, costing, QC, shipping) and **ready-to-send RFQ emails**.

## AI: optional, granular, any model
The app is a complete tool without AI. When you want help:
- **Chat** with Claude, OpenAI, Gemini, OpenRouter, Groq, Mistral, DeepSeek, xAI, Together, or **local / edge** models (Ollama, LM Studio, llama.cpp, vLLM, any OpenAI-compatible server). Pick the model per provider.
- **You choose what the AI may design**: shape & pattern, stitching, materials, colour & dye, prints & paint, trims, jewelry, production.
- **Image tools**: Nano Banana / Nano Banana Pro (Gemini), OpenAI images, Higgsfield or any custom endpoint. Render your 3D design photoreal, or turn an image into a fabric print.
- **MCP server** for Claude Desktop / Claude Code, Codex, Gemini CLI, Cursor, Windsurf, VS Code: agents design live in the open app.
- **CLI**: `gft "make a waxed field jacket in olive, size L"`.
- **Blender**: *Open in Blender* sends the current design straight into your installed Blender (desktop app), or exports a GLB on the web. Agents can also drive Blender through a Blender MCP server next to this app's.
- **Higgsfield**: generate renders, videos and ideas with Higgsfield via its MCP server (best) or an HTTP endpoint.

→ Step-by-step setup: [docs/AI.md](docs/AI.md)

## Run it

| | |
|---|---|
| **Web** | https://the-potential-dropout.github.io/genzineers-fashion-tool/: works in Chrome, Edge, Safari (macOS/iOS), Firefox and Samsung Internet on desktop, tablet and phone. |
| **Desktop** | [Releases](https://github.com/the-potential-dropout/genzineers-fashion-tool/releases): Windows (.exe), macOS (.dmg), Linux (.AppImage / .deb / .rpm). Built with Tauri: ~10 MB installer, uses the system WebView. |
| **From source** | `npm install && npm run dev` |

```bash
npm install
npm run dev              # web app → http://localhost:5173
npm test                 # sews and drapes every template headless
npm run build            # static build in dist/
npm run desktop:build    # desktop installer (needs Rust + Tauri prerequisites)
npm run mcp              # MCP server (stdio)
npm run cli -- help      # command line
```
