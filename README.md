## What it does

**Four steps, nothing overwhelming:** Style → Materials → Details → Make it. Every choice comes with an industry-default recommendation and a one-line reason, so you can go deep or just accept the defaults.

### Clothing, hats & bags
- **161 parametric templates** (141 clothing, knitwear, underwear, hosiery, hat & bag + 20 jewelry): crew/V-neck tees, undershirts, tanks & A-shirts, henleys, polos, oxford & dress shirts, hoodies, crew sweats, denim trucker, bomber, biker, racer, waxed field jacket, Harrington, chore coat, varsity, puffer, parka, rain shell, anorak, gilet, single- and double-breasted blazers (notch / peak / shawl lapels), suits, waistcoats, overcoats, trench, peacoat, dresses, skirts, jeans, chinos, cargo, joggers, 5" and 7" shorts, scarves, ties, bow ties, and all kinds of hats (tuque/beanie, slouch, bucket, fedora, trilby, Panama, beret, 6-panel baseball cap, snapback, trucker, dad cap, 5-panel, flat cap, visor) and bags (tote, shopper, duffel, weekender, handbag, clutch, crossbody, sling, fanny pack, backpack, messenger, bucket, baguette, hobo).
- **Customise everything**: fit, length, sleeves, cuffs (rib, barrel, French, button-tab, zip, storm…), necklines, collars, lapels, closures, pockets, vents, belts, rise, leg shape, waistbands, hems, cap bill inserts (polyethylene, cardboard, buckram…), bag handles, closures and hardware.
- **Any body**: realistic CC0 male & female mannequins; size charts XXS–4XL **or** custom height, weight, chest/bust, underbust, waist, hips, thigh, shoulder width, inseam, arm length, neck and head, plus body-shape presets (hourglass, pear, apple, rectangle, inverted triangle, athletic, petite, tall, plus, slim). Mesh, collisions and patterns all follow the body.
- **Tailoring**: take in / let out chest, waist, hips, thigh; lengthen / shorten body, sleeves, legs; adjust shoulders and leg openings, with a **fit map** (red = tight, blue = loose).
- **Hosiery & socks**: tights, pantyhose, fishnets, stockings, hold-ups, footless tights, no-show to over-knee socks; denier, yarn, patterns (fishnet, micro-net, rib, cable, argyle, stripes, lurex, back seam), lace / rib / welt tops, reinforced toe & heel, cushioning.
- **Zippers**: metal (brass, antique brass, nickel, gunmetal, aluminium, premium polished), nylon coil, invisible, water-resistant, moulded, reversible, decorative; #3–#10; closed / open-end / two-way; auto-lock / non-lock / reversible sliders; puller styles; industry defaults per garment.
- **Decorative edges & lacing**: scalloped, lettuce, picot, ruffle, frayed, pinked, piped, bias-bound, blanket stitch, ric-rac, fringe, lace, pom-pom, feather, sequin edges; crisscross, ladder, corset and spiral lacing with eyelets.
- **Parametric sizing**: men's / women's / unisex charts XXS–4XL or your own measurements. Patterns *and* the avatar re-draft; the tech pack includes the graded spec.
- **Fabrics with real quality differences**: 166 fabrics and qualities across 63 families (virgin wool, Super 130s, Japanese selvedge denim, distressed / stone-washed / acid-wash denim, pre-shrunk / combed / Pima / Supima / organic cotton, Egyptian poplin, waxed cotton, ripstop, ballistic nylon, PFAS-free waterproof membranes…), **fibre blends** with pros/cons (CVC 60/40, T/C 65/35, tri-blend, 98/2 stretch denim, 80/20 nylon-spandex…), and **insulation** (goose/duck down by fill power, synthetic microfibre, wool batting, kapok, aerogel…).
- **Underwear & lingerie**: men's briefs, trunks, boxer briefs, boxer shorts, long johns; women's bikini, hipster, thong, high-waist, boyshort, lace bralette, sports bra, underwire balconette, bandeau, camisole. Brief cuts, rise, leg height and waistbands (exposed jacquard, fold-over, picot, laser-cut bonded); bras with band/cup sizing, straps (standard, racer, halter, convertible, strapless), closures, underwire and padding/moulded foam; intimates fabrics (nylon-elastane microfibre, modal, power mesh, stretch lace, bra foam, stretch satin) and lingerie hardware (hooks & eyes, sliders, rings, underwire, picot/plush/fold-over elastics).
- **Knitwear**: fully-fashioned, whole-garment (seamless), cut & sew, circular, hand-knit and crochet; gauges 1.5–18gg; 18 yarns (extra-fine merino, Shetland, Aran, cashmere, mohair-silk, alpaca, cotton, linen…); 23 stitch structures (jersey, rib 1x1/2x2, fisherman rib, Milano, garter, seed/moss, cables, Aran, honeycomb, pointelle, lace, popcorn, waffle, tuck, jacquard, Fair Isle, intarsia…); colourwork motifs (Fair Isle bands, Nordic star, argyle, birdseye, houndstooth, snowflake yoke) with a printable **knitting chart**; 13 knit templates. Knit choices change weight, stretch and drape in the simulation.
- **Assembly**: every ISO 4915 stitch class plus seam constructions, hand stitches, bonding & glue, ultrasonic / RF / laser welding, seam taping, fusing, rivets, linking and whole-garment knitting, with **thread materials** (core-spun, bonded nylon, silk, aramid, PTFE, conductive steel…).
- **Colour, dye, print & paint**: 20+ dye methods (reactive, garment-dyed, indigo rope, dope-dyed, tie-dye, shibori, batik, ombré…), 25 print designs (tartan, houndstooth, argyle, chevron, zebra, snakeskin, ikat, ditsy floral…) and 20 print methods (screen plastisol/water-based/discharge, DTG, DTF, sublimation, puff, foil, devoré…), paints, and fibre-compatibility checks.
- **Trims & decorations**: 76 buttons, fasteners and decorations (horn, corozo, MOP, jeans tacks, snaps, zips, studs, spikes, rhinestones, pearls, sequins, chains, fringe, patches…).
- **Realistic male & female mannequins** (CC0, generated from MakeHuman) graded to every size, with collision shapes fitted to the mesh so cloth rests on the body you see.
- **Real cloth simulation**: sew-then-drape like garment CAD, with strain limiting, gathering, insulation loft, and body collisions. It runs in **Rust → WebAssembly** (20 KB, zero-copy to the GPU) and sleeps when settled, so it uses no CPU at idle.

### Jewelry
Rings, chains (19 link types incl. cable, curb, Cuban, figaro, rope, box, franco, byzantine, paperclip, tennis), necklaces, pendants, bracelets, bangles, cuffs and earrings, with clasps, bails and backs; 34 gems with real refractive index & dispersion; 17 cuts incl. custom; 14 settings; **karat control** (purity, density, colour, hallmark), platings; custom outlines for pendants, stones, links and signets; **import CAD parts** (STL, OBJ, GLB, 3MF, PLY, FBX, DAE, STEP, IGES, .blend) and resize, stretch and distort them to fit; metal weight & carat estimates; STL export for casting.

### Make it
One click for a **tech pack** (flats, BOM, construction, colour/print spec, graded measurements, labels/care, QC/AQL), **DXF** pattern for factory CAD, **SVG**, **tiled print-at-home PDF**, **BOM CSV**, **GLB/OBJ/STL**, a step-by-step **production guide** (finding mills, trim suppliers and factories, sampling, costing, QC, shipping) and **ready-to-send RFQ emails**.

## AI: optional, granular, any model
The app is a complete tool without AI. When you want help:
- **Chat** with Claude, OpenAI, Gemini, OpenRouter, Groq, Mistral, DeepSeek, xAI, Together, or **local / edge** models (Ollama, LM Studio, llama.cpp, vLLM, any OpenAI-compatible server). Pick the model per provider.
- **You choose what the AI may design**: shape & pattern, stitching, materials, colour & dye, prints & paint, trims, jewelry, production.
- **Image tools**: Nano Banana / Nano Banana Pro (Gemini), OpenAI images, Higgsfield or any custom endpoint. Render your 3D design photoreal, or turn an image into a fabric print.
- **MCP server** for Claude Desktop / Claude Code, Codex, Gemini CLI, Cursor, Windsurf, VS Code: agents design live in the open app.
- **CLI**: `gft "make a waxed field jacket in olive, size L"`.
- **Blender**: *Open in Blender* sends the current design straight into your installed Blender (desktop app), or exports a GLB on the web. Agents can also drive Blender through a Blender MCP server next to this app's.
- **Higgsfield**: generate renders, videos and ideas with Higgsfield via its MCP server (best) or an HTTP endpoint.

→ Step-by-step setup: [docs/AI.md](docs/AI.md)

## Run it

| | |
|---|---|
| **Web** | https://the-potential-dropout.github.io/genzineers-fashion-tool/: works in Chrome, Edge, Safari (macOS/iOS), Firefox and Samsung Internet on desktop, tablet and phone. |
| **Desktop** | [Releases](https://github.com/the-potential-dropout/genzineers-fashion-tool/releases): Windows (.exe), macOS (.dmg), Linux (.AppImage / .deb / .rpm). Built with Tauri: ~10 MB installer, uses the system WebView. |
| **From source** | `npm install && npm run dev` |

```bash
npm install
npm run dev              # web app → http://localhost:5173
npm test                 # sews and drapes every template headless
npm run build            # static build in dist/
npm run desktop:build    # desktop installer (needs Rust + Tauri prerequisites)
npm run mcp              # MCP server (stdio)
npm run cli -- help      # command line
```
